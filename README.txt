유정의 오늘도 한 걸음 - 랜딩페이지 원본 파일

구성 파일
- index.html : 랜딩페이지 본문
- style.css : 색상과 화면 디자인
- script.js : 화면 효과와 버튼 기능
- favicon.svg : 사이트 아이콘

사용 방법
1. 압축을 풉니다.
2. index.html 파일을 더블클릭하면 컴퓨터에서 페이지를 볼 수 있습니다.
3. GitHub, Vercel 등의 서비스에 파일들을 그대로 올려 웹사이트로 사용할 수 있습니다.
